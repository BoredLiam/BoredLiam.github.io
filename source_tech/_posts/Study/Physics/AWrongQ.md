2026陕晋宁青卷15题(压轴)的第三问实际上是一道错题，在此给出我的研究和思考。

<!-- more -->

## 原题

<img src="194658/Q.jpg" style="width:50%;" alt="原题目"/>

读题我们可以得到以下的过程图：

![题目描述示意图](194658/1.png)

先解决（1）（2）问

{% note info %}
解：（1）
在$t_{1}$时间内$A$和$B$组成的系统动量守恒：
$$mv_{0}=mv_{1}+4mv_{1}$$
解得
$$v_{1}=\frac{v_{0}}{5}$$

（2）
同理设$A$在$t_{1}$时间内位移为$x_{A}$
根据系统动量守恒，对于$A$和$B$在在$t_{1}$时间内每一刻都有
$$mv_{A}+4mv_{B}=mv_{0}$$
两边同时在$0$~$t_{1}$内积分得
$$mx_{A}+4mx_{B}=mv_{0}t_{1}···①$$
设$t_{1}$时刻$A$和$B$组成的系统电势能为$E_{p2}$，初始时刻$A$和$B$组成的系统电势能为$E_{p1}=\frac{1}{25}mv_{0}^{2}$
则根据电势能的性质
$$\frac{E_{p1}}{E_{p2}}=\frac{l_{0}+x_{B}-x_{A}}{l_{0}}$$
解得$E_{p2}=\frac{11}{25}mv_{0}^{2}···②$
知道了电势能自然用能量守恒，在$t_{1}$时间内$A$和$B$组成的系统能量守恒：
$$E_{p1}+\frac{1}{2}mv_{0}^{2}=\frac{1}{2}5mv_{1}^{2}+E_{p2}···③$$
联立上述①②③式得到
$$x_{B}=\frac{1}{5}v_{0}t_{0}-\frac{2}{11}l_{0}$$
{% endnote %}

接下来我们按照一般的思路，发现初始状态和$t_{1}+t_{2}$时刻状态电势能相同，直接列出全过程冲量和能量守恒式，于是就有了参考答案的思路：

{% note info %}
（3）
设恒力大小为$F$
对于$t_{1}+t_{2}$全过程列冲量定理
$$mv_{0}+Ft_{2}=4mv_{0}···④$$
能量守恒
$$\frac{1}{2}mv_{0}^{2}+Fl_{0}=\frac{1}{2}4mv_{0}^{2}···⑤$$
联立④⑤两式得到
$$t_{2}=\frac{2l_{0}}{v_{0}}$$
{% endnote %}
这么来看，答案简洁，解法也很优美，只可惜这答案并不对。

## 反驳1

那么我们如何反驳呢？
在此之前，我们先求解一下从$t_{1}$到$t_{1}+t_{2}$的过程中$A$和$B$分别的位移$x_{A1}$和$x_{B1}$
稍加注意，我们便可以发现$x_{A1}$和$x_{B1}$正好分别是$t_{1}$时刻和$t_{1}+t_{2}$时刻$A$$B$间的距离
![位移示意图](194658/3.png)
所以我们根据前述题目条件有
$$x_{B1}=l_{0}$$
$$x_{A1}=\frac{E_{p1}}{E_{p2}}l_{0}=\frac{1}{11}l_{0}$$
完成了前置工作，我们从$t_{1}$时刻开始画出$v-t$图像
![从$t_{1}$开始的$v-t$图像](194658/2.png)
因为$A$和$B$分别做加速度减小的运动，故图像呈现一凹一凸的两条曲线。
如左图所示，$S_{1}$显然代表了$A$和$B$间距离的变化量，即
$$S_{1}=x_{B1}-x_{A1}=\frac{10}{11}l_{0}$$
而右图画出的三角形，我们计算其面积$S_{2}$得
$$S_{2}=\frac{1}{2}·v_{0}·\frac{2l_{0}}{v_{0}}=l_{0}$$
根据图像应有
$$S_{1}>S_{2}$$
即
$$\frac{10}{11}l_{0}>l_{0}$$
这显然不成立，故该题存在错误。

## 反驳2

当然还有一种反驳方式，即利用质心求解
![质心位移示意图](194658/4.png)
我们分别求出$t_{1}$和$t_{1}+t_{2}$时刻$A$和$B$系统的质心位置和速度
以$P$点为坐标原点分别求出两个时刻质心$C$的坐标
$$\frac{m·(-\frac{1}{11}l_{0})+4m·0}{5m}=-\frac{1}{55}l_{0}$$
$$\frac{m·0+4m·l_{0}}{5m}=\frac{4}{5}l_{0}$$
以及速度
$$\frac{m·\frac{v_{0}}{5}+4m·\frac{v_{0}}{5}}{5m}=\frac{v_{0}}{5}$$
$$\frac{m·0+4m·v_{0}}{5m}=\frac{4}{5}v_{0}$$
接下来分别对质心运用动能定理和冲量定理
$$F(\frac{1}{55}l_{0}+\frac{4}{5}l_{0})=\frac{1}{2}5m(\frac{4v_{0}}{5})^{2}-\frac{1}{2}5m(\frac{v_{0}}{5})^{2}$$
$$Ft_{2}=5m·\frac{4}{5}v_{0}-5m·\frac{1}{5}v_{0}$$
联立解得
$$F=\frac{11mv_{0}^{2}}{6l_{0}}$$
$$t=\frac{18l_{0}}{11v_{0}}$$
显然解得答案与标准答案不同，也说明该题存在错误。

## 纠正

实际上，对于$t_{1}+t_{2}$时刻的限定条件太多了，导致这道题出现了条件之间矛盾的问题。
题目的限定有三：

1. $t_{1}+t_{2}$时$B$的速度为$v_{0}$
2. $A$的速度为$0$
3. $A$和$B$相距为$l_{0}$

实际上知道了1.和2.已经可以求出3.的值以及题目所求的$t_{2}$，过程如下：

首先，去掉条件3.并不影响前述$x_{A1}$和$x_{B1}$的求解，所以依然有
$$x_{B1}=l_{0}$$
$$x_{A1}=\frac{E_{p1}}{E_{p2}}l_{0}=\frac{1}{11}l_{0}$$
这些作为已知条件。
接下来列出全过程动量式
$$Ft_{2}=5m·\frac{4}{5}v_{0}-5m·\frac{1}{5}v_{0}=3mv_{0}···①$$
以及全过程能量式
设$t_{1}+t_{2}$时刻$A$和$B$组成的系统电势能为$E_{p3}$
$$F·x_{B1}=\frac{1}{2}4mv_{0}^{2}-\frac{1}{2}5m(\frac{v_{0}}{5})^{2}+E_{p3}-E_{p1}···②$$
$$E_{p3}=E_{p1}\frac{l_{0}}{x_{B1}}···③$$
此外，还需要在质心上列出一条式子
质心$C$在两个时刻的速度依旧有
$$\frac{m·\frac{v_{0}}{5}+4m·\frac{v_{0}}{5}}{5m}=\frac{v_{0}}{5}$$
$$\frac{m·0+4m·v_{0}}{5m}=\frac{4}{5}v_{0}$$
质心的位移$x_{C1}$可以用两种方法求出
其一是根据质心仅受一个恒力作用，做匀加速直线运动，有
$$x_{C1}=\frac{\frac{v_{0}}{5}+\frac{4v_{0}}{5}}{2}t_{2}=\frac{1}{2}v_{0}t_{2}$$
其二是质心的定义式
$$x_{C1}=\frac{mx_{A1}+4mx_{B1}}{5m}=\frac{x_{A1}+4x_{B1}}{5}$$
综合二式得到
$$x_{C1}=\frac{1}{2}v_{0}t_{2}=\frac{x_{A1}+4x_{B1}}{5}···④$$
最后只需联立①②③④，令$r=\frac{x_{B}}{l_{0}}$，可以得到方程
$$913r^{2}-161r-2=0$$
这实在看着不太美，不过还是可以用求根公式解出
$$r=\frac{161+5\sqrt{1329}}{1826}$$
于是$A$和$B$之间的距离终于解出为
$$x_{B}=\frac{161+5\sqrt{1329}}{1826}l_{0}$$
根据④式代入可以解出$t_{2}$
$$t_{2}=\frac{161+5\sqrt{1329}}{913}\frac{l_{0}}{v_{0}}$$

## 结语

看来，在研究物体的运动过程中，我们除了对系统、对全过程列出能动量守恒的式子外，还要考虑对单个物体、某个过程列出牛顿运动定律等等的式子，以免遗漏条件。在这种情况下，对于质心的研究往往能让我们事半功倍：在本题中，质心$C$的运动不同于往常“人船模型”中的匀速直线运动，而是匀加速运动，由此，我们或许可以引申出更多的性质......
